# Testing Plan

|---|---|
| Submit valid Network Request | Request is created |
| Submit request for approval | Approval is generated |
| Approve request | Fulfillment task is created |
| Reject request | Request is rejected/closed |
| Network Team receives task | Task is assigned correctly |
| Engineer updates task | Work notes/state are updated |

| Request completed | Requester receives completion notification |
| Unauthorized user attempts restricted action | Access is denied |
| Dashboard/report is opened | Request metrics are visible |
